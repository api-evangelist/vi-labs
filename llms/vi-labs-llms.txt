# Vi Labs

> Vi Labs (vi.co) builds an enterprise AI orchestration platform for healthcare,
> biopharma and wellness organizations, connecting first-party and third-party
> data, predictive models, patient and provider engagement, and operational
> workflows. Its products are Vi Data Web, Vi Activate, Vi Engage, Vi Operate
> and Vi Pulse.

Generated by the API Evangelist enrichment pipeline on 2026-09-02 from the
company's own public surface. Vi Labs does not publish an llms.txt of its own
(https://vi.co/llms.txt returns 404), and publishes no developer documentation,
no OpenAPI and no SDK.

## What an agent can actually reach

- [Vi Labs MCP server](https://vi.co/wp-json/mcp/mcp-oauth-server): Model
  Context Protocol endpoint on the vi.co host. Live but OAuth-protected —
  an anonymous tools/list returns HTTP 401 with an RFC 9728
  `WWW-Authenticate: Bearer ... resource_metadata=...` challenge. Tool names and
  input schemas require an authenticated introspection.
- [OAuth authorization server metadata](https://vi.co/.well-known/oauth-authorization-server):
  RFC 8414. issuer https://vi.co, authorization_code + refresh_token, PKCE S256,
  single scope `mcp`, client_id metadata documents supported.
- [OAuth protected resource metadata](https://vi.co/.well-known/oauth-protected-resource):
  RFC 9728. Names the MCP endpoint above.
- [MCP route index](https://vi.co/wp-json/mcp): public WordPress REST route
  listing, enumerating `mcp-oauth-server` and `mcp-adapter-default-server`.

## What an agent cannot reach

- https://api.vi.co/ — the enterprise platform host. An AWS API Gateway that
  answers every path, including every /.well-known/ path, with HTTP 403
  `ForbiddenException`. No metadata, no documentation, no anonymous surface.
- No OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract is published on
  any Vi Labs host.
- No developer portal, API reference, quickstart, sandbox, status page,
  changelog or pricing page exists in the company's own sitemap.
